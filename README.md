# gui-qml Fuzzing Artifacts

This repository stores fuzzing artifacts produced by the
[gui-qml](https://github.com/bitcoincore-dev/gui-qml) CI.

- `corpus/` — accumulated libFuzzer corpus inputs
- `crashes/` — crash reproducers from the latest run
- `coverage/` — code coverage report (also served via GitHub Pages)

Live coverage report: https://bitcoincore-dev.github.io/gui-qml-fuzzing/
